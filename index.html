Document GPT: RAG Chatbot for PDF Intelligence

Python, Chatbots, LLMs, Langchain, Gradio, OpenAI, Generative AI

Implemented a chat-with-your-data RAG workflow end-to-end using Langchain, OpenAI, and Gradio. A PDF document is loaded using PyPDF and split into smaller chunks with a recursive character text splitter. Vector embeddings are then generated from these chunks and stored in a Chroma vector store for easy semantic search. A user question is taken and passed into two LLMs; text-davinci for similar document retrieval (which helps in detecting metadata info, e.g, page number, from the question) and gpt-3.5-turbo-0301 for generating an answer based on the retrieved documents.
